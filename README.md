# 🐄 CowMonitor UI — منصة الرعاية الذكية للماشية وأطواق إنترنت الأشياء

واجهة مستخدم عصرية فائقة الاحترافية لمنصة **CowMonitor** المخصصة لإدارة قطعان الأبقار الذكية ومراقبة أطواق الاستشعار اللاسلكية (**ESP32 IoT Collars**).

---

## 🌟 الميزات الرئيسية (Key Features)

1. **لوحة القيادة الميدانية (Field Command Dashboard):**
   - مؤشرات الأداء الحيوية (KPIs) اللحظية (إجمالي القطيع، إنتاج الحليب، الأبقار تحت العلاج).
   - مؤشر الإجهاد الحراري (**THI - Temperature Humidity Index**) لحماية الإنتاجية من تقلبات الطقس.
   - رسوم بيانية حية متزامنة لمتوسط درجات الحرارة ومعدلات الاجترار على مدار 24 ساعة.
   - قائمة فرز سريعة (Triage) للأبقار التي تستوجب التدخل الطبي الفوري.

2. **إدارة قطيع الأبقار (Herd Hub):**
   - عرض شبكي جذاب (Card Grid) وعرض جدولي متقدم (Data Table).
   - بحث فوري وفلاتر متقدمة بحسب الحظيرة (أ، ب، العزل، الحوامل، التجفيف) أو الحالة الصحية.
   - نافذة تسجيل بقرة جديدة وتعيين طوق ESP32 بضغطة زر.

3. **ملف البقرة التفاعلي 360° (Cow Profile 360):**
   - كشف الشبق التلقائي (**Estrus Peak Detection**) مع حساب احتمالية الإخصاب وتحديد نافذة التلقيح المثالية.
   - سجل قياسات الحساسات اللحظية (درجة الحرارة، دقائق الاجترار، النشاط الحركي، جودة إشارة LoRa/WiFi).
   - سجل طبي وملاحظات بيطرية تفاعلية مع إمكانية طلب فحص عاجل.

4. **مركز التنبيهات والإنذار المبكر (Smart Alerts Center):**
   - تصنيف التنبيهات حسب الخطورة (حرجة، تحذيرات، معلومات عامة).
   - إرشادات بيطرية استباقية عند كل تنبيه مع إمكانية تأكيد المتابعة.

5. **أسطول أجهزة وأطواق ESP32 (IoT Fleet Management):**
   - مراقبة حالة البطاريات، مستويات الإشارة (RSSI)، والإصدارات البرمجية.
   - معالج اقتران سريع للأطواق الجديدة.

6. **إعدادات متقدمة وثيمات مرنة (Settings & Themes):**
   - دعم الوضع الداكن الفاخر (Dark Mode) والوضع النهاري فائق التباين (Light Mode).
   - تخصيص عتبات إنذار الحمى وانخفاض الاجترار.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19 + Vite
- **Icons:** Lucide Icons
- **Design System:** Vanilla CSS Glassmorphism + Dynamic Themes (Dark / Light)
- **Typography:** Cairo & Outfit (Google Fonts)

## 🚀 التشغيل المحلي (Quick Start)

```bash
# الانتقال إلى مجلد المشروع
cd D:\CowMonitorUI

# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```
